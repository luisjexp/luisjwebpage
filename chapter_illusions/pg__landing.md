## How do illusions help us understand the brain?
An important question in visual neuroscience is how the brain allows us to see. We want to understand how different parts of the visual system work together to process visual scenes.

One useful way to study vision is to ask why visual illusions occur. Indeed, illusions can be especially informative because they reveal cases in which perception departs from the physical stimulus, and in doing so, they can help us understand not only vision, but the brain more broadly. In this sense, studying illusions is a bit like debugging a computer program: when a program produces an unexpected output, we can dig into the code to figure out where the issue lies. As we debug, we learn how different parts of the program work in isolation and how they shape the final output. Odd visual percepts can be thought of in a similar way.

Here, we will try to understand why these visual illusions occur by “debugging” the visual system and examining the processes that give rise to them.
